# tiny-nn

A neural network library built from scratch with NumPy.

The goal of this project is to understand neural networks, gradients, and backpropagation from first principles by implementing the core components manually.

## Current focus

* NumPy
* Tensor shapes
* Forward passes
* Gradients
* Backpropagation

## Philosophy

This project prioritizes understanding over abstraction. High-level deep learning frameworks are intentionally avoided during the early stages.
